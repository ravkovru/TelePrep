# TelePrep — Telegram API Access Assistant

Небольшая macOS-утилита, которая помогает пройти подготовительный этап получения `api_id` и `api_hash` Telegram через `my.telegram.org`.

## Возможности

- `nslookup my.telegram.org`;
- проверка внешнего IP и страны `KZ` в рабочем режиме;
- диагностика HTTP, timeout, reset и SSL/DPI-сбоев;
- временная настройка `/etc/hosts` с восстановлением;
- открытие `my.telegram.org` в приватном окне Safari;
- очистка DNS-кэша после завершения;
- отсутствие сохранения номера, кода, `api_id` и `api_hash`.

## Демо-режим

Демо проходит полный цикл с условными данными, не требует VPN и не считает отсутствие KZ ошибкой. Он открывает приватное окно Safari, очищает DNS-кэш и возвращает интерфейс к исходному состоянию.

## Рабочий режим

Подключите VPN с казахстанским IP, запустите программу и нажмите «VPN подключён — продолжить». Только после подтверждения страны `KZ` программа продолжит работу.

## Сборка

```bash
swift build -c release
swift run KZTelegramAPIUtility
```

Рабочий режим может запросить пароль администратора для временной настройки `/etc/hosts` и разрешение macOS на управление Safari через System Events.

Публичные VLESS-конфигурации не встроены в приложение. Не используйте неизвестные публичные VPN-узлы для банков, почты или ввода секретов.
