# Получение Telegram API ID и Hash

Скрипт автоматизирует только сетевую подготовку. VPN перед запуском нужно подключить вручную к Казахстану.

```bash
chmod +x telegram-api-setup.sh
./telegram-api-setup.sh
```

Если DNS не возвращает адрес из-за блокировки:

```bash
TELEGRAM_IP=149.154.167.220 ./telegram-api-setup.sh
```

Скрипт делает резервную копию `/etc/hosts`, добавляет временную запись, очищает DNS-кэш, открывает `my.telegram.org`, а после нажатия Enter восстанавливает исходный файл. При прерывании через `Ctrl+C` восстановление также выполняется автоматически.

`api_id` и `api_hash` вводятся и сохраняются вручную: код авторизации Telegram и секрет API не должны проходить через скрипт или попадать в его логи.

Для сетевого теста через прокси:

```bash
PROXY_URL=http://IP:PORT ./telegram-api-setup.sh
```

Поддерживаются HTTP/HTTPS и SOCKS5-адреса, например `socks5h://IP:PORT`. Это проксирует запросы скрипта. Уже открытый браузер автоматически не перенастраивается; публичные прокси нельзя использовать для ввода номера, кода Telegram или других секретов.
