# TelePrep — помощник для получения Telegram API

TelePrep — приложение для macOS, которое помогает подготовить доступ к [my.telegram.org](https://my.telegram.org) и открыть страницу для получения `api_id` и `api_hash`. Авторизация и создание приложения выполняются пользователем в Safari.

> В репозитории опубликован исходный код версии 3.5.1 с экспериментальной поддержкой прокси. Готовый установщик в GitHub Releases пока не опубликован. Текущий код не следует считать готовым для широкого использования: восстановление системных настроек прокси реализовано неполно, а операции с hosts и Safari требуют дополнительной проверки.

## Что понадобится

- macOS 13 или новее и Safari;
- Xcode или инструменты командной строки Apple со Swift;
- работающий HTTP или SOCKS5-прокси для рабочего режима;
- доступ к своему аккаунту Telegram, чтобы получить код входа.

Для открытия приватного окна могут потребоваться разрешения macOS на управление Safari и «Универсальный доступ» для управления через System Events. Для изменения `/etc/hosts` и очистки DNS-кэша требуются права администратора.

## Установка и запуск

Склонируйте репозиторий и запустите приложение из папки проекта:

```bash
git clone https://github.com/ravkovru/TelePrep.git
cd TelePrep
swift run KZTelegramAPIUtility
```

Для сборки без запуска:

```bash
swift build -c release
```

## Режимы и работа с прокси

Демо запускается без прокси, показывает тестовые данные и пытается открыть приватное окно Safari.

В рабочем режиме приложение выполняет `nslookup my.telegram.org`, позволяет ввести адрес и данные HTTP или SOCKS5-прокси, проверить соединение и применить прокси к системным настройкам Wi‑Fi. Затем выполняются проверка внешнего IP и HTTPS-доступа, попытка изменить `/etc/hosts` и открыть приватное окно Safari. Страна IP отображается справочно.

Для VLESS необходим отдельный совместимый клиент и его локальный прокси-порт. Одновременная работа VPN может изменить фактический маршрут; проверяйте внешний IP непосредственно в Safari. Вход в Telegram и получение `api_id` и `api_hash` пользователь выполняет самостоятельно.

## Известные ограничения

- Кнопка сброса отключает системные прокси Wi‑Fi и **не восстанавливает ранее установленные настройки**. Сохраните настройки заранее и проверьте их после работы.
- Для изменения системных настроек и `/etc/hosts` используются команды `sudo`; в графическом приложении запрос прав и результат команд не гарантированы. Перед запуском сохраните резервную копию `/etc/hosts`.
- Приложение может сообщить об открытии приватного окна или восстановлении настроек, не подтвердив фактическое выполнение. Проверяйте это самостоятельно.
- Для одного адреса Froxy в коде зафиксирован IP сервера; он может измениться. Это временное решение.
- Установщик 3.5.1 не подписан; публичный релиз и полноценное тестирование установки пока не выполнены.

Не публикуйте `api_hash`, коды входа Telegram, данные прокси или ссылки на личные VPN-подписки.
