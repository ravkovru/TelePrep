# TelePrep — помощник для получения Telegram API

TelePrep — приложение для macOS, которое помогает подготовить доступ к [my.telegram.org](https://my.telegram.org) и открыть страницу для получения `api_id` и `api_hash`. Авторизация и создание приложения выполняются пользователем в Safari.

> В репозитории сейчас опубликована ранняя версия с внешним VPN. Версия с вводом прокси и установщиком `.pkg` здесь пока не опубликована; публичных релизов с готовым установщиком нет.

## Что понадобится

- macOS 13 или новее и Safari;
- Xcode или инструменты командной строки Apple со Swift;
- работающий внешний VPN с выходным IP в Казахстане для рабочего режима;
- доступ к своему аккаунту Telegram, чтобы получить код входа.

Для открытия приватного окна могут потребоваться разрешения macOS на управление Safari и «Универсальный доступ» для управления через System Events. Для изменения `/etc/hosts` и очистки DNS-кэша требуются права администратора.

## Установка и запуск

Склонируйте репозиторий и запустите приложение из папки проекта:

```bash
git clone https://github.com/ravkovru/TelePrep.git
cd TelePrep
swift run KZTelegramAPIUtility
```

Для сборки без запуска:

```bash
swift build -c release
```

## Демо

Оставьте включённым переключатель «Демо» и нажмите «Запустить проверку». Приложение выполняет DNS-проверку, показывает условный IP Казахстана и пытается открыть приватное окно Safari. В демо запись `/etc/hosts` не изменяется; приложение также пытается очистить системный DNS-кэш.

## Рабочий режим

1. Отключите «Демо» и нажмите «Запустить проверку». Сначала выполняется `nslookup my.telegram.org`.
2. Когда приложение попросит, подключите внешний VPN с выходом в Казахстане и нажмите «VPN подключён».
3. Приложение проверяет внешний IP и страну. Если страна не определена как KZ, выполнение останавливается.
4. Затем приложение проверяет HTTPS-доступ к `my.telegram.org`, используя полученный DNS-адрес, пытается добавить временную запись в `/etc/hosts` и открыть приватное окно Safari.
5. В Safari войдите в Telegram и откройте **API development tools**, чтобы создать приложение и получить `api_id` и `api_hash`.

После работы нажмите кнопку восстановления со стрелкой: она пытается вернуть сохранённую копию `/etc/hosts` и очистить DNS-кэш. Эта ранняя версия вызывает системные команды через `sudo`; в графическом приложении запрос пароля и выполнение команд не гарантированы. Перед использованием проверьте системные настройки и наличие резервной копии `/etc/hosts`.

## Если что-то не работает

- **Страна не KZ:** проверьте активный VPN и внешний IP; TelePrep не подключает VPN самостоятельно.
- **Safari не открыл приватное окно:** проверьте разрешения macOS для автоматизации и управления компьютером, затем откройте приватное окно вручную.
- **Нет доступа к сайту:** проверьте интернет и VPN, затем повторите запуск. Получение DNS-адреса само по себе не подтверждает доступность сайта.
- **Несколько VPN или прокси включены одновременно:** фактический маршрут Safari может отличаться от ожидаемого. Проверьте внешний IP непосредственно в Safari.

Не публикуйте `api_hash`, коды входа Telegram, данные прокси или ссылки на личные VPN-подписки.
